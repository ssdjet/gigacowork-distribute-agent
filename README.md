# Агент распределения заказов (GigaCowork)

Агент распределяет новые упаковочные листы (ФУЛ) поставщиков между
логистами и готовит строки для реестра заказов Cloud. Все решения
принимает детерминированный скрипт Python; модель запускает скрипт,
прикрепляет результат и кратко отвечает по шаблону.

## Состав

```
distribute-agent.zip
├── skill/
│   ├── SKILL.md                  # навык: когда применять, как запускать, как отвечать
│   ├── scripts/
│   │   └── distribute.py         # вся бизнес-логика (Python 3 + openpyxl, без сети)
│   └── references/
│       └── rules.md              # правила распределения и принятые допущения
└── system_prompt.txt             # системный промпт агента
```

Зависимости скрипта: Python 3.8+, openpyxl. Стандартная библиотека иначе.

## Установка в GigaCowork

1. Распакуйте архив.
2. Создайте (или откройте) агента, вставьте текст `system_prompt.txt`
   в системный промпт.
3. Подключите навык из папки `skill/` (файл `SKILL.md` — точка входа,
   скрипты и справочники подтягиваются из `scripts/` и `references/`).
4. Сохраните агента. Доступ к внешним системам не нужен.

## Запуск

Пользователь выбирает агента, прикладывает три файла Excel и отправляет
сообщение (текст не обязателен):

- выгрузка ФУЛ из 1С (дата, cutoff, номер, статус, комментарий с номером
  заказа, способ доставки, бренд, контрагент, страна);
- реестр Cloud (12 колонок реестра);
- список сотрудников из 1С (ФИО, состояние, должность, таб. №).

Колонки ищутся по заголовкам: допустимы другой порядок колонок, лишние
колонки, другие названия листов.

Модель выполняет команду вида:

```bash
python3 scripts/distribute.py --files <файл1> <файл2> <файл3> --out <папка>
```

и возвращает `result.xlsx` с листами «Новые строки Cloud» (12 колонок по
форме реестра), «Повторные отправки», «Возможные пропуски»,
«Требует внимания», «Журнал решений».

## Проверка без GigaCowork (прямой запуск скрипта)

```bash
pip install openpyxl
# сгенерировать тестовые данные и эталон (создаются в test-data/):
python3 test-data/generate_test_data.py

python3 skill/scripts/distribute.py \
    --ful test-data/ful_1c.xlsx \
    --cloud test-data/cloud_registry.xlsx \
    --staff test-data/staff_1c.xlsx \
    --out ./result
# сверка с эталоном:
python3 test-data/check_results.py ./result/result.xlsx
```

Файлы Excel и PDF-отчёт — генерируемые артефакты и в git не хранятся:
тестовые данные воспроизводятся генератором выше. Результаты контрольных
прогонов: 3 запуска, 100% совпадение с эталоном (20/20 ФУЛ, все поля),
0 выдуманных значений, идентичный SHA-256 результата, ~0,2 с на пачку.
