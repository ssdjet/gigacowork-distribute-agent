# Установка и запуск

## Требования

| Компонент | Версия | Для чего |
|---|---|---|
| GigaCowork | — | загрузка агента (навык + системный промпт) |
| Python | 3.8+ | локальный запуск скрипта и проверка |
| openpyxl | 3.x | чтение/запись Excel |

Сеть и внешние сервисы скрипту не нужны: он работает только с приложенными файлами.

## 1. Установка агента в GigaCowork

1. Скачайте `distribute-agent.zip` из папки с артефактами
   (ссылка в README, раздел «Артефакты для сдачи») и распакуйте.
2. В GigaCowork создайте нового агента или откройте существующего.
3. Вставьте содержимое `system_prompt.txt` в системный промпт агента.
4. Подключите навык: загрузите `skill.zip` (внутри — `skill/SKILL.md`,
   `skill/scripts/distribute.py`, `skill/references/rules.md`).
   Точка входа навыка — `SKILL.md` с YAML-заголовком (`name`, `description`).
5. Сохраните агента. Коннекторы и доступы к внешним системам не требуются.

## 2. Локальная установка (для проверки и разработки)

```bash
git clone https://github.com/ssdjet/gigacowork-distribute-agent.git
cd gigacowork-distribute-agent
pip install openpyxl

# сгенерировать синтетические данные и эталон (в test-data/):
python3 test-data/generate_test_data.py
```

## 3. Проверка установки

```bash
python3 skill/scripts/distribute.py \
    --ful test-data/ful_1c.xlsx \
    --cloud test-data/cloud_registry.xlsx \
    --staff test-data/staff_1c.xlsx \
    --out ./result

python3 test-data/check_results.py ./result/result.xlsx
```

Ожидаемый вывод скрипта (сводка):

```json
{
  "всего_фул": 20,
  "новых_строк_cloud": 18,
  "повторных_отправок": 1,
  "дублей_в_пачке": 1,
  "возможных_пропусков": 1,
  "требует_внимания": 6,
  "без_логиста": 5,
  "файл": "./result/result.xlsx",
  "последняя_запись_cloud": "22.10.2026"
}
```

Ожидаемый вывод сверки: `полностью совпало: 20 (100%)`,
`Выдуманных значений: 0`, `Форма Cloud: OK`.

Если счётчики совпали — установка корректна. Проверка занимает ~0,2 с.

## 4. Обновление

- Правила и допущения: правьте `skill/references/rules.md` и при
  необходимости `skill/scripts/distribute.py`, затем перезагрузите навык.
- Системный промпт меняется отдельно от навыка — после правки
  `system_prompt.txt` обновите его в настройках агента.

## Устранение неполадок

| Сообщение / симптом | Причина | Что делать |
|---|---|---|
| `ERROR: требуется openpyxl` | не установлена зависимость | `pip install openpyxl` |
| `не найден лист с колонками ...` | в файле нет ожидаемых заголовков | сверьте заголовки с `docs/usage.md`; скрипт ищет их в первых 15 строках каждого листа |
| `ERROR: не переданы файлы: ...` | не хватает одного из трёх файлов | передайте все три; роли можно указать явно `--ful/--cloud/--staff` |
| Пустые даты в результате | дата в нестандартном формате | допустимы `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, `ДД/ММ/ГГГГ`, Excel-даты |
| Результат отличается между прогонами | входные файлы изменились | скрипт детерминирован: при неизменных файлах SHA-256 результата совпадает |
