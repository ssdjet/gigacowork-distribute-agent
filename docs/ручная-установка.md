# Ручное добавление агента в GigaCowork

Эта инструкция подходит для установки без Python, Git и автоматических скриптов.
Потребуется только браузер и доступ к рабочему пространству GigaCowork.

> Ручная установка и контрольный запуск подтверждены в рабочем пространстве:
> агент запустил навык и вернул ожидаемую сводку. Содержимое полученного
> `result.xlsx` можно дополнительно сверить с `expected_result.xlsx`.

## 1. Скачайте и подготовьте файлы

Откройте [папку с артефактами для сдачи](https://files.sberdisk.ru/s/lzcvNuSQDef3b9C)
и скачайте:

- `distribute-agent.zip` — агент и навык;
- `test-data.zip` — тестовые Excel-файлы и эталон.

Распакуйте `distribute-agent.zip`. Для установки понадобятся:

- `skill.zip` — весь навык одним архивом;
- `system_prompt.txt` — системная инструкция агента.

**`skill.zip` не распаковывайте.** Внутри него уже находятся:

```text
skill/SKILL.md
skill/scripts/distribute.py
skill/references/rules.md
```

Форма GigaCowork принимает один файл навыка. Поэтому загружать нужно именно
один `skill.zip`, а не отдельный `SKILL.md`: иначе скрипт и справочник не попадут
в навык.

## 2. Откройте форму создания агента

Перейдите в рабочее пространство и откройте создание агента:

[Создать агента в GigaCowork](https://way.cowork.ru/workspaces/64d8061e-0468-4522-b884-69e225f39caf/agents/new)

Для другого рабочего пространства откройте раздел агентов и нажмите кнопку
создания нового агента.

## 3. Заполните основные поля

В поле **«Название»** введите:

```text
Распределение ФУЛ между логистами
```

В поле **«Описание»** введите:

```text
Распределяет новые ФУЛ поставщиков между логистами, учитывает историю Cloud, загрузку и доступность сотрудников и формирует result.xlsx.
```

Для поля **«Инструкция»**:

1. Откройте `system_prompt.txt` в «Блокноте» или другом текстовом редакторе.
2. Выделите весь текст: `Ctrl+A`.
3. Скопируйте его: `Ctrl+C`.
4. Вставьте в поле **«Инструкция»**: `Ctrl+V`.
5. Проверьте, что текст вставлен полностью, без сокращений.

## 4. Загрузите навык одним ZIP-файлом

1. Прокрутите страницу до блока **«Навыки»**.
2. Нажмите **«+»**.
3. В окне **«Загрузите файл навыка»** нажмите на область выбора файла.
4. Выберите `skill.zip`.
5. Нажмите **«Далее»** и дождитесь завершения загрузки.
6. Если в окне уже выбран `SKILL.md`, сначала удалите его значком корзины,
   затем выберите `skill.zip`.

Блоки **«Команды»** и **«Интеграции»** оставьте пустыми. Коннекторы к 1С,
Cloud, почте и внешним API для работы агента не нужны.

## 5. Сохраните агента

Нажмите **«Сохранить»** внизу страницы.

Если кнопка неактивна:

- проверьте поля «Название», «Описание» и «Инструкция»;
- убедитесь, что загрузка навыка завершена;
- проверьте, что в навык загружен именно `skill.zip`.

Каждое открытие страницы `/agents/new` предназначено для создания нового агента.
Для изменения существующего агента открывайте его настройки, а не создавайте копию.

## 6. Выполните контрольный запуск

1. Распакуйте `test-data.zip`.
2. Откройте чат с созданным агентом.
3. Прикрепите одновременно три файла в любом порядке:
   - `ful_1c.xlsx`;
   - `cloud_registry.xlsx`;
   - `staff_1c.xlsx`.
4. Не прикладывайте `expected_result.xlsx`: это эталон для последующей сверки.
5. Отправьте сообщение без текста.

Агент должен запустить навык без уточняющих вопросов и вернуть `result.xlsx`.

## 7. Проверьте результат

Ожидаемая сводка:

| Показатель | Ожидаемое значение |
|---|---:|
| Всего ФУЛ | 20 |
| Новых строк Cloud | 18 |
| Повторных отправок | 1 |
| Дублей внутри пачки | 1 |
| Возможных пропусков | 1 |
| Требует внимания | 6 |
| Без логиста | 5 |

В `result.xlsx` должны быть пять листов:

1. «Новые строки Cloud» — ровно 12 колонок в порядке реестра;
2. «Повторные отправки»;
3. «Возможные пропуски»;
4. «Требует внимания»;
5. «Журнал решений».

Для полной проверки сравните результат с `expected_result.xlsx` или запустите
локальную сверку по [общей инструкции](installation.md). Дополнительно спросите
агента: «Почему заказ отдан этому логисту?» Ответ должен ссылаться на основание
из «Журнала решений», а не предлагать новое распределение.

## Если установка не удалась

| Симптом | Решение |
|---|---|
| Форма пишет «Можно загрузить только один файл» | Это ожидаемо: загрузите один `skill.zip`, содержащий весь навык |
| Загружен только `SKILL.md` | Удалите его корзиной и загрузите `skill.zip` |
| ZIP не отображается в окне выбора | Проверьте, что вы распаковали внешний `distribute-agent.zip` и выбираете внутренний `skill.zip` |
| Агент не запускает обработку | Проверьте, что системная инструкция вставлена полностью и навык сохранён |
| Агент просит уточнить файлы | Прикрепите одновременно все три Excel-файла; порядок не важен |
| Счётчики отличаются | Используйте файлы именно из `test-data.zip` и сверьте версию навыка с репозиторием |

После успешной установки не передавайте другим людям свой браузерный профиль
или активную сессию GigaCowork.
