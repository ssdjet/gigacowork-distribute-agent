# Распределение ФУЛ между логистами

## Когда применять навык

Пользователь выбрал агента распределения заказов и приложил файлы Excel:
выгрузку ФУЛ из 1С, реестр Cloud (история заказов) и список сотрудников из 1С.
Сообщение может быть без текста — это нормальный сценарий запуска.

Файлы могут называться как угодно, листы внутри — тоже. Порядок колонок может
отличаться, лишние колонки допустимы. Скрипт находит колонки по заголовкам.

## Что делать

1. Сохраните приложенные файлы и определите их роли. Если неясно, какой файл
   какой, не гадайте по имени — скрипт сам определит роль по заголовкам:

   ```bash
   python3 scripts/distribute.py --files <файл1> <файл2> <файл3> --out <папка_результата>
   ```

   Роли также можно передать явно:

   ```bash
   python3 scripts/distribute.py --ful <фул_1с.xlsx> --cloud <реестр.xlsx> \
       --staff <сотрудники.xlsx> --out <папка_результата>
   ```

2. Скрипт создаёт в папке результата файл `result.xlsx` с листами:
   «Новые строки Cloud» (12 колонок строго по форме реестра), «Повторные
   отправки», «Возможные пропуски», «Требует внимания», «Журнал решений» —
   и печатает в stdout JSON со сводкой.

3. Прикрепите `result.xlsx` к ответу и напишите пользователю короткое
   сообщение строго по шаблону (числа возьмите из JSON):

   > Готово. Новых строк Cloud: N. Повторных отправок: M (дублей внутри
   > пачки: K). Возможных пропусков: P. Требует внимания: Q — см. лист
   > «Требует внимания». Без логиста: R (группа недоступна или не определена).

4. Если пользователь спрашивает, почему заказ отдан конкретному логисту,
   отвечайте по листу «Журнал решений»: там основание каждого назначения
   (история работы с поставщиком, отпуска, текущая загрузка).

## Жёсткие ограничения

- Не придумывайте группы, логистов и недостающие данные. Если данных нет,
  скрипт уже поставил «не определено» — передавайте это как есть.
- Не переназначайте и не «исправляйте» решения скрипта. Если результат
  кажется спорным, покажите основание из «Журнал решений» и предложите
  пользователю решить вручную.
- Не обращайтесь к 1С, Cloud, почте и любым внешним системам. Только
  приложенные файлы.
- Не меняйте правила распределения. Если случай не покрыт — добавьте ФУЛ
  в «Требует внимания» со своей формулировкой и явно скажите, что правило
  не описано.
